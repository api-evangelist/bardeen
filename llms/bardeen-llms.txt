# Bardeen

> Bardeen is an AI automation platform from Bardeen Inc (San Francisco, CA) that automates
> repetitive go-to-market work — web scraping, web search, contact and company enrichment, and
> AI-assisted data tasks — from a browser extension that runs against the sites and SaaS tools a
> user is already logged into. Work is metered in credits, not API calls. The company also ships
> WIQ (getwiq.ai), a "Workflow Intelligence Platform" that reconstructs business processes from
> browser and system-of-record data.

## Machine-readable contract status

Bardeen publishes NO public API. Verified 2026-08-29 by probing every host the company controls:
- No OpenAPI/Swagger at /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json, /api-docs
  or /redoc on www.bardeen.ai, bardeen.ai or www.getwiq.ai (all 404).
- No GraphQL endpoint (/graphql 404), no AsyncAPI, no gRPC/.proto, no WSDL.
- No MCP server and no A2A agent card (/.well-known/agent-card.json and /.well-known/agent.json
  return 404 on every host).
- No /.well-known documents of any kind, including security.txt.
- docs.bardeen.ai does not resolve (NXDOMAIN). https://www.bardeen.ai/developer-program, which
  once advertised early SDK access, 301s to the homepage. The 3,155-URL sitemap contains no API,
  developer, SDK or webhook page.
Integration with Bardeen happens inside the product (native connectors to Google Sheets, Airtable,
Notion, Salesforce, HubSpot, Pipedrive, Salesloft, Outreach, Lemlist and others) and through
generic HTTP GET/POST actions that Bardeen makes as a CLIENT of other people's APIs.
